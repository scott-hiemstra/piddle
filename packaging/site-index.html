@NAME@ packages

Version @VERSION@ for x86_64 and ARM64 Linux, signed with key @FPR_SPACED@ (key.asc).

Add the repository once, and then @GUI@ brings what it needs along, and updates arrive with your normal system updates. On a server, install just @NAME@. Release notes and the individual files are on GitHub.

Debian, Ubuntu

sudo install -d /etc/apt/keyrings
curl -fsSL @URL@/key.asc | sudo tee /etc/apt/keyrings/@NAME@.asc >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/@NAME@.asc] @URL@/deb ./" | sudo tee /etc/apt/sources.list.d/@NAME@.list
sudo apt update
sudo apt install @NAME@ @GUI@

Fedora, RHEL, openSUSE

sudo curl -fsSLo /etc/yum.repos.d/@NAME@.repo @URL@/rpm/@NAME@.repo
sudo dnf install @NAME@ @GUI@

dnf asks you to confirm the key on first use; check that its fingerprint is the one above. On openSUSE, use sudo zypper addrepo @URL@/rpm/@NAME@.repo and zypper install.

Arch Linux

curl -fsSL @URL@/key.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key @FPR@
printf '\n[@NAME@]\nServer = @URL@/arch/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu @NAME@ @GUI@
